# ماذا لو استيقظت فجأة في بلاد الرافدين قبل 4000 سنة؟
### ملف إنتاج فيلم كارتوني سينمائي قصير (3D) — حوالي 7 دقائق + نسخة ريلز 60 ثانية

علي، شاب بغدادي، يصحى على انقطاع الكهرباء، وختم طيني قديم من جده يسحبه عبر الزمن:
**أور السومرية (~2050 ق.م)** ← **بابل حمورابي (~1755 ق.م)** ← **بابل نبوخذنصر وبوابة عشتار (~575 ق.م)** ← ويرجع لغرفته… وبجيبه لوح طين عليه كف ولد سومري.

## كيف تحققت شروط المشروع

| الشرط | الحل |
|---|---|
| قصة متكاملة، مو عرض صور | بطل، صديقين (لو-نانا ونُبتا)، مطاردة، وداع، ومفاجأة بالنهاية. كل معلومة تطلع من حدث (الساعة ← النظام الستيني، الميزان ← الشيقل، التحية ← قرابة الأكدية والعربية). |
| بطل واحد بنفس الشكل | مواصفات ثابتة + كتلة `[ALI]` تنلصق بكل برومبت + صورة مرجعية واحدة. |
| مشاهد مترابطة | البطارية عدّاد تنازلي (3% ← 0%)، ولوح لو-نانا وختم الجد يربطون البداية بالنهاية. |
| معلومات موثوقة | ملف تدقيق كامل يفصل الحقيقة عن الدراما. |
| عدم خلط العصور | **ثلاث** قفزات بدل اثنين، لأن حمورابي وبوابة عشتار بينهم ~1200 سنة — وصارت لحظة مفاجأة بالقصة ("البوابة بعدها ما انبنت!"). |
| أول 5 ثواني قوية | پنكة توقف + مولدة تطفى + موبايل بلا شبكة + ختم يضوي — كلها قبل الثانية 6. |
| لا كتابة عربية مشوّهة | برومبت سلبي يمنع أي نص، وكل العناوين والتواريخ بالمونتاج فقط. |

## خطوات الإنتاج المقترحة

1. **سجّلوا التعليق الصوتي** من ملف السيناريو (المعلّق + صوت علي).
2. **ولّدوا الصور المرجعية** للشخصيات الثلاث والختم (ملف 03، القسم ب) واعتمدوا نسخة وحدة.
3. **ولّدوا اللقطات** صورة أولى ← فيديو، على ترتيب الأرقام.
4. **ركّبوا اللقطات القريبة للآثار** من صور متاحف حقيقية (ملف 04، القسم 4).
5. **المونتاج:** العناوين، بطاقات التواريخ، الترجمة، الموسيقى والمؤثرات (ملف 02، القسم 8).
6. **راجعوا قائمة الممنوعات** (ملف 02، القسم 9).
7. **مراجعة علمية** سريعة من مختص قبل النشر.
