# برومبتات توليد الصور والفيديو

> **الدقة:** ولّدوا كل شي **1080p (1920×1080، 16:9)**. لا تكتبون «4K» أو «8K» بالبرومبت ولا تحتاجون ترفيع للدقة.
> **الأدوات:** صورة أولى (Midjourney / Flux / Imagen) ← تحويلها فيديو (Kling / Veo / Runway / Hailuo) بنفس البرومبت + سطر الحركة.
> **ثبات البطل:** ولّدوا صورة مرجعية وحدة للبطل (REF-HERO) واستعملوها مرجعاً بكل لقطة يظهر بيها.
> **الشاشات والكتابة:** الهاتف واللابتوب يتولّدون بشاشة فاضية أو مضيئة بدون كتابة، والرسالة والعدّاد ينضافون بالمونتاج.

## د. نصائح ثبات وجودة

- **ثبات الوجه:** استعملوا REF-HERO بكل لقطة (Character reference أو Elements أو Ingredients). نفس الشي لـ REF-OLDMAN.
- **الساعة والندبة:** راجعوا كل لقطة يظهر بيها المعصم أو الحاجب، لأن هذني مفتاح المفاجأة.
- **مدة التوليد:** 5–8 ثواني لكل لقطة، وقصّوها بالمونتاج.
- **الشاشات:** دائماً فاضية أو مضيئة بدون كتابة. الرسالة والعدّاد ينحطون بالمونتاج بخط عربي نظيف.
- **الذكريات (6.5–6.8 و2.5):** ولّدوها عادي، وبالمونتاج أضيفوا حبيبات فيلم، ودرجة لون باهتة دافئة، وإطار خفيف.
